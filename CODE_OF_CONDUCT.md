# Code of Conduct

Jenny is maintained by one person in their spare time. This document is short on
purpose: it says what is expected, what is not, and what happens if that line is
crossed.

## What is expected

- **Assume good faith.** Most disagreements here are about trade-offs, not about
  people. Argue the trade-off.
- **Be specific.** "It's broken" costs the maintainer an hour of guessing.
  "It crashes on Android 11 with provider X, here's the logcat" gets fixed.
- **Accept that "no" is an answer.** This project has a deliberate scope
  (Android-only, local-first, single unified session). A feature can be a good
  idea and still not belong here.
- **Respect people's privacy.** Never paste someone else's data — or your own
  API keys, tokens, or conversation history — into an issue.

## What is not acceptable

- Harassment, insults, or personal attacks — including about someone's
  nationality, gender, sexuality, disability, religion, age, or appearance.
- Sexual language or imagery.
- Publishing private information about anyone without their explicit consent.
- Sustained disruption: reopening settled decisions to wear people down,
  brigading, or demanding unpaid work as though it were owed.
- Using issues, PRs, or discussions to promote unrelated products.

This applies to every space the project owns: issues, pull requests, code
review, commit messages, and discussions.

## Enforcement

The maintainer will remove, edit, or lock content that breaks these rules, and
may block accounts that keep doing it. There is no appeals committee — it's one
person making a judgment call, and that call errs on the side of keeping the
space usable for everyone else.

## Reporting

If someone's behaviour is a problem, report it privately rather than in a public
thread: open a private report through GitHub (*Security → Report a
vulnerability* also reaches the maintainer privately if no other private channel
is available), or send a direct message via the maintainer's GitHub profile.

Reports are read by the maintainer only. Say what happened, where, and who was
involved. You will not be penalised for reporting in good faith, even if the
conclusion is that no action is needed.
