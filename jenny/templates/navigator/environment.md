# Environment Model

Write here the external realities that affect your plans: policies, institutions,
industry changes, official statistics, first-hand results. The Navigator reads
this file when it reasons about whether a route is still viable.

Keep the source type visible on every line, for example:

- Official fact: (source, date) — what is explicitly stated.
- Policy / institutional arrangement: (source, date) — what is allowed or required.
- Official trend judgement: (source, date) — an institution's forecast.
- Professional forecast: (source, date) — an expert or industry prediction.
- Company strategy: (source, date) — a company's stated direction.
- First-hand experience: (who, date) — what you actually observed.
- Real outcome: (date) — what happened when something was tried.

"Official" does not mean infallible. When a judgement matters, look for a
counter-example before treating it as settled.

This file is yours. The Navigator reads it and never writes it.
